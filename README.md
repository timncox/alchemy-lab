# alchemy-lab

The homepage for all of Tim Cox's firmware for the
[Hermetic Modular Alchemy Lab](https://hermeticmodular.com/modules/alchemy-lab):
one Eurorack module, nine instruments, explained for people who don't
play synthesizers. Live at https://timncox.github.io/alchemy-lab/.

| Instrument | What it is | Source | Status |
|---|---|---|---|
| Mark | five-track looper | [mark-alchemy](https://github.com/timncox/mark-alchemy) | played on the module |
| Belt | voice tuning + harmonies | [belt-alchemy](https://github.com/timncox/belt-alchemy) | played on the module |
| Smack | loop capture, slicing, glitch | [smack-alchemy](https://github.com/timncox/smack-alchemy) | played on the module |
| Clouds, Elements, Marbles, Plaits, Warps, Meld | Mutable Instruments ports | [mi-alchemy](https://github.com/timncox/mi-alchemy) | built and tested on a computer; not yet heard |

The whole site is `docs/index.html` (GitHub Pages serves `release:/docs`).
The panel drawing uses the geometry generated by
mi-alchemy's `tools/emit_panel_geometry.py` from the SDK's KiCad panel.
